Nova 0.1.4 —— 编辑器交互修复（热修）。

## 变化

- **"按了没反应、再按别的键才生效"修复**：ctrl+c 清空输入框、ctrl+v 粘贴、alt+↑ 队列还原等编程式编辑器改动此前不重绘屏幕（状态变了屏幕不动）——现在即按即变。

## 安装

macOS / Linux：

```bash
curl -fsSL https://github.com/RNA-Nova/nova/releases/latest/download/install.sh | sh
```

Windows（PowerShell 自带）：

```powershell
irm https://github.com/RNA-Nova/nova/releases/latest/download/install.ps1 | iex
```

> 已装旧版重跑安装命令即可升级。

完整工程变更记录见 [CHANGELOG.md](https://github.com/RNA-Nova/nova/blob/v0.1.4/CHANGELOG.md)。

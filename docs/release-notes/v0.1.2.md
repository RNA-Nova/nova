Nova 0.1.2 —— Windows 体验与冻结形态依赖自足。

## 变化

- **Windows 一键安装落地**：`install.ps1`（PowerShell 5.1 自带即可）——校验/链接翻转/自检/编程能力包/Git Bash 供给/PATH 注册全链，`uninstall` 对称摘除；
- **冻结形态不再依赖 pip 宿主**：第三方 Python 依赖（如 Pillow）新增免 pip 的 wheel 解包通道——无系统 Python 的机器也装得上、读图可用；rg 收进框架托管二进制注册表（与 fd 同通道，pin + 上游官方 sha256），grep/find 原生加速开箱即用；
- **Windows 黑窗清零**：启动连接瞬间与子代理/工具调用的控制台弹窗全部消除；
- **Windows bash 工具挂起修复**：此前 TUI 里 bash 卡片要再发一条消息才出结果——根因（子进程继承协议 stdin 管道，Git Bash 启动卡死）已根治，即发即回；
- **TUI 启动时序正经化**：连接期显示"正在连接后端…"，窗口期的输入经就绪门排队补发，不丢不错位；
- **TUI 首启自检装包**：绕过安装器的进入路径（手动解压/绿色版）首启引导安装编程能力包；
- 冻结态 print 模式收尾的 httpcore2 噪音、装包子进程输出泄漏防护失效（OutputGuard）等存量问题一并修复。

## 安装

macOS / Linux：

```bash
curl -fsSL https://github.com/RNA-Nova/nova/releases/latest/download/install.sh | sh
```

Windows（PowerShell 自带，零前置——含编程能力包与 Git Bash 供给）：

```powershell
irm https://github.com/RNA-Nova/nova/releases/latest/download/install.ps1 | iex
```

> 已装旧版的用户重跑安装命令即可升级——新版本落 `releases/0.1.2/` 并翻转链接，旧版本目录保留可手动清理。

完整工程变更记录见 [CHANGELOG.md](https://github.com/RNA-Nova/nova/blob/v0.1.2/CHANGELOG.md)。

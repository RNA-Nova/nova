Nova 0.1.0 —— 首个公开发布（Alpha）。

Nova 是构建与运行 LLM 智能体的分层框架 + 开箱即用的终端编程助手：装完即可在终端里驱动一个能读写文件、执行命令、委派子代理的编程助手；框架层可用来组装自己的 agent 产品。

## 安装

```bash
curl -fsSL https://github.com/RNA-Nova/nova/releases/latest/download/install.sh | sh
```

零系统依赖（不需要预装 Node.js / Python）。支持 macOS arm64/x64、Linux x64/arm64、Windows x64/arm64（Windows 手动下载 zip 解压）。校验、源码安装与卸载见[安装文档](https://github.com/RNA-Nova/nova/blob/v0.1.0/docs/installation.md)。

## 这个版本里有什么

- **`nova` 终端界面**：会话树（fork/分支导航/恢复）、上下文自动压缩、会话内 slash 命令、只读规划模式（`/plan`）、主题与键位自定义；
- **官方双 bundle**：`nova-base`（内建：会话基础设施）+ `nova-coding-agent`（编程能力：bash/edit/grep 等 8 工具 + scout/planner/reviewer/worker 子代理），后者按需 `nova-server pkg install npm:nova-coding-agent`；
- **框架三层**（可独立使用）：`nova_ai` 多厂商 LLM 抽象（Volcengine / Moonshot AI / Kimi Coding / 任意 OpenAI 兼容端点）、`nova_agent` 事件驱动异步 Agent 框架、`nova_harness` 高阶会话 SDK + JSON-RPC 服务器（自写前端的通道）；
- **包生态**：工具/扩展/agent 组合/persona/模板等七类资源按包分发，path/git/npm 三源安装，用户级/项目级双作用域。

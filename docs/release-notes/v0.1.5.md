Nova 0.1.5 —— 首启体验与 Windows 完整性。

## 变化

- **首启引导链修通**：登录模型服务成功后自动选好该厂商的默认模型——登录完直接开聊（此前首条消息会撞"No model selected"又被指引回 /login）；首启引导文案去行话（"登录 provider"→"登录模型服务"），删掉零可用模型状态下的死路选项。
- **启动期对话框不再抢焦点**：慢后端上首启引导/装包询问可能比你的手迟到——现在编辑器里已有草稿就不弹，不再吃掉在飞输入。
- **Windows 剪贴板上线**：ctrl+v/alt+v 文本粘贴与 ctrl+x 复制回复在 Windows 自此可用（PowerShell 通道，中文不乱码）；VS Code 终端里 ctrl+v 被宿主吃掉时用 alt+v。
- **Windows 无 bash 的首启引导**：绕过安装器的进入路径（手动解压/绿色版）会在首启收到 bash 缺失提示与三条出路（装 Git for Windows / 加 PATH / 设 shell_path）。
- **pkg install 跨盘符修复**：path 源与配置目录不在同一盘符（如 D: 源码 + C: 配置）时，装完包在登记步骤崩溃——已修。
- **/persona 旋钮拆除**：人格文本的唯一装配点收敛回 agent 组合声明（换人格 = `/agent` 换角色）；bundle 人格目录拍平为 `coding.md`/`worker.md` 平铺。
- **install.ps1 在 VS Code 终端不再崩**（Expand-Archive 进度条在无常驻进度 UI 的宿主抛异常——已静默）。
- 工程面：PTY 键位验证跨平台化（CI 新增 macOS + Windows 双腿全绿——启动、键位、剪贴板、退出键逐键断言）。

## 安装

macOS / Linux：

```bash
curl -fsSL https://github.com/RNA-Nova/nova/releases/latest/download/install.sh | sh
```

Windows（PowerShell 自带）：

```powershell
irm https://github.com/RNA-Nova/nova/releases/latest/download/install.ps1 | iex
```

> 已装旧版重跑安装命令即可升级。

完整工程变更记录见 [CHANGELOG.md](https://github.com/RNA-Nova/nova/blob/v0.1.5/CHANGELOG.md)。

Nova 0.1.3 —— Windows 体验修复集与切换链路正经化。

## 变化

- **子代理并行委派不再互踩/不再每启重装**：npm 包改为"装了即不重装"（本地版本判定）+ 跨进程安装锁——并行 worker 委派稳定，后端/子代理冷启动显著加快；
- **Windows 黑窗清零**：启动连接瞬间与子代理/工具调用的控制台弹窗全部消除；
- **Windows bash 输出中文正常**：cmd/powershell 等原生程序的 OEM 代码页输出正确解码（不再 `版本`→`汾`）；
- **/agent 切换干净**：切角色清掉旧 persona override（不再 scout 人格配 worker 工具的混搭）；/persona 切换只换人格文本不动能力面；
- **footer 缓存命中率是真理**（此前分母错误恒显 100%）；
- **主题切换后状态指示器即时换色**；
- **弱网/无外网机器启动不再卡死**：模型目录刷新改后台，首屏即开。

## 安装

macOS / Linux：

```bash
curl -fsSL https://github.com/RNA-Nova/nova/releases/latest/download/install.sh | sh
```

Windows（PowerShell 自带，零前置——含编程能力包与 Git Bash 供给）：

```powershell
irm https://github.com/RNA-Nova/nova/releases/latest/download/install.ps1 | iex
```

> 已装旧版的用户重跑安装命令即可升级——新版本落 `releases/0.1.3/` 并翻转链接，旧版本目录保留可手动清理。

完整工程变更记录见 [CHANGELOG.md](https://github.com/RNA-Nova/nova/blob/v0.1.3/CHANGELOG.md)。
